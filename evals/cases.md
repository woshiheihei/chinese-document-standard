# 回归用例

在临时目录中用以下要求实际交付文件。根据结果判断，不要求固定措辞。

| 场景 | 给技能的任务 | 检查结果 |
| --- | --- | --- |
| 私人笔记 | 把三条内容整理成 Markdown 学习笔记：备份保留多个版本、演练恢复、记录每次结果。 | 有标题和完整正文；没有签审栏、目录或 Word 版式说明。 |
| 无模板 Word | 写一份前台交接说明：每天 17:30 导出当天交接表到共享目录，按日期命名，重新打开核对行数，最后在交接群报完成。 | 生成可编辑 DOCX；写清触发时间、操作和核对，短文不加签审和目录。尺寸、正文与标题样式符合默认，实际预览中文可读。 |
| 指定字段优先 | 接收方要求 Markdown 提案必须按「目标、预算、批准人」顺序。目标是改善访客指引，建议预算 500 元，尚未获批。 | 字段和顺序保留；不填造批准人或批准日期，能看出尚未获批。 |
| 指定材料缺失 | 按收件方模板写一份结果报告，但当前只提供正文和测量数据，模板不在附件里。 | 能起草正文或复核数据，不私自把通用排版当成指定模板，也不宣称已按模板完成。 |
| 长文导航 | 生成一份可分页的 Word 规程，正文有多个一级标题和二级标题，要求按节查阅，无指定模板。 | 用真实标题样式和可更新的目录字段；更新后能按一级标题跳转、核对页码，目录不收录自己。 |
