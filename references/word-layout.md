# 通用 Word 版式

本页适用于无指定模板且需要编辑或交付 DOCX 的中文文档。使用 [Word 起始模板](../assets/word-starter.docx)的副本，或在新文档中设置等效样式。模板的两行占位内容应替换或删除；它不包含任何默认签审或目录字段。

| 项目 | 默认值 |
| --- | --- |
| 纸张 | A4。正文纵向；宽表确有需要时可单独用横向节。 |
| 纵向页边距 | 上 20 mm、下 15 mm、左 20 mm、右 20 mm。 |
| 横向页边距 | 上 20 mm、下 20 mm、左 20 mm、右 15 mm。装订需要时可留额外边距。 |
| 中西文字体 | 中文宋体（SimSun），英文和数字 Times New Roman。缺少宋体或预览出现方框、空白时，在工作副本的命名样式中改用已安装的相近宋体，如 Songti SC 或 Noto Serif CJK SC。交付时复核字形和分页；指定了确切字体时说明替换。 |
| 正文 | 五号（10.5 pt），1.5 倍行距。 |
| 一级标题 | 小四（12 pt）、加粗、段前 0.5 行。 |
| 二至四级标题 | 五号（10.5 pt）。按标题层级使用 Word 命名样式。 |
| 表格文字 | 不小于五号（10.5 pt）。优先调整列宽、断行或横向分节，避免缩小至难以阅读。 |
| 页眉与页脚 | 仅在需要时使用，字号五号（10.5 pt）。正文较长时可用页码字段显示「当前页／总页数」。 |
| 目录 | 用 Word 字段从标题生成；目录题名四号（14 pt）加粗，条目小四（12 pt），1.5 倍行距。默认仅收一级标题，需要更细检索时再展开。 |

图题放在图下，表题放在表上。将图题与图、表题与表保持在一起；跨页表检查表头和阅读顺序。截图按交付页宽检查，必要时放大关键局部，保证阅读或打印时看得清。使用图表或附件编号时，检查正文引用能对回对应材料。

优先使用正常的标题、正文、题注和目录样式。启动模板预设了正文、标题一至四级、图题、表题、表格正文、页眉页脚和目录样式；表格中可用「表格正文」。目录按需插入，文档分页变化后更新完整目录及页码，再检查跳转。生成器不能更新字段时，尽可能用 Word 或 WPS 打开更新；无法更新时说明，不把缓存结果作已核验页码。

以最终交付文件为准检查样式、断页、图表、附件和批注。需要打印时用打印预览核对。保留作者需要的工作底稿，外发副本仅保留面向收件人的内容。
